CodeAlpha Web Scraping Project

Project Description

This project uses Python to extract book information from a website and save the collected data in a CSV file for further analysis.

Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas

Libraries Installation

Run this command in the terminal:

python -m pip install requests beautifulsoup4 pandas

Files

- "web_scraping.py" — Python script for web scraping.
- "books_data.csv" — CSV file containing the collected book data.

How to Run

1. Install the required libraries.
2. Open the project folder in VS Code.
3. Run the following command:

python web_scraping.py

If "python" is not recognized, try:

py web_scraping.py

Output

The scraped book information is stored in a CSV file for further use.

Learning Outcomes

- Learned basic web scraping using Python.
- Understood HTML structure and data extraction.
- Learned to save collected data in CSV format.
